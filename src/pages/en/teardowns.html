How a teardown is done

  • {{icon:check}}Fetch without scripts. We read the HTML a crawler receives before any JavaScript runs.
  • {{icon:check}}Count, do not rate. Words, headings, structured data types, question and answer pairs. Numbers you can check yourself.
  • {{icon:check}}Ask the buyer's questions. We list what a buyer would want from the page and whether the page says it.
  • {{icon:check}}Say what to change first. A short list, ordered by effort and effect.
