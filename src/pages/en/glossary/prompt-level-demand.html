In more detail

Keyword tools report searches by phrase. Assistants receive longer, more specific questions, and the same need can be phrased in hundreds of ways. Since no public figure exists, the honest approach is to estimate demand from where buyers already tell you: sales calls, support tickets, the questions prospects raise in a first meeting and the audience questions in a webinar's Q&A.

Google says its AI features can issue multiple related searches for one question, a technique it calls query fan-out. A real buyer question therefore touches several sub-topics, and the list of prompts you track should include both the long question and the sub-questions behind it.

An example

"Which approach to supplier risk works for a mid-size manufacturer with suppliers in several countries" is one prompt. "How often should suppliers be reviewed" and "annual audit or continuous monitoring" are sub-questions. A list of ten such prompts, frozen and run monthly, is a workable proxy for demand.
