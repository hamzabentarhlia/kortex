The rules, an example and the common mistake. h1: hreflang summary: A label that links the language versions of a page. kind: term kicker: Glossary date: 2026-11-14 modified: 2026-11-14 in_short: hreflang is an annotation that tells search engines the language and regional versions of a page and which one to show to which user. Each version must list itself and every other version, and the links must be reciprocal. ---

In more detail

Google describes three equivalent ways to indicate alternate versions: HTML link elements, HTTP headers and the sitemap. Alternate URLs must be fully qualified, an x-default value can name a fallback page for unmatched languages, and if two pages do not point to each other the annotations are ignored. Google does not use hreflang or the lang attribute to detect a page's language; it reads the visible content.

An example

A site with English, French and Arabic versions of its pricing page gives each of the three pages the same set of four annotations: en, fr, ar and x-default, each with a full https address. The common mistake is a French page that points to English when the English page does not point back, so the pair is ignored.

Source: Tell Google about localized versions of your page, Google Search Central.
